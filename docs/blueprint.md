# **App Name**: TRANSMITTER BY LINDO.SHOOT UNDER THE PEEKARDO COLLECTIVES PTY LTD

## Core Features:

- Budget Setup: Set monthly budgets for different spending categories.
- Expense Logging: Log individual expenses with details like date, amount, and category for an interactive experience.
- Spending Summaries: View summaries of spending by category and date range for easy analysis.
- Budget vs. Actual: Monitor progress against the set budget with intuitive and clear visuals and dashboards.
- Budget Suggestion: Use an AI tool to suggest optimized budgets based on past spending data and advanced budgeting rules.
- Export data: Allows user to export their data as a spreadsheet for external analysis and reporting.

## Style Guidelines:

- Primary color: Forest green (#388E3C) for a fresh and professional look, echoing financial growth and stability.
- Background color: Soft white (#F5F5F5) to create a clean, uncluttered interface and enhance readability.
- Accent color: Mint green (#B9F6CA) for interactive elements and key highlights, drawing attention to actionable items.
- Body and headline font: 'Inter', a sans-serif font, to maintain a modern and readable style.
- Use clear, minimalistic icons to represent each spending category and feature, for intuitive navigation.
- A well-structured, tab-based layout for seamless navigation between budget settings, expense logging, and spending summaries, similar to CSG but more intuitive.
- Use subtle animations when new data appears, enhancing user engagement.
